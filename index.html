How to use

01

Add to bookmarks

Drag FontPeek above to your bookmarks bar, or use Copy code and save the snippet as a bookmark URL.

02

Activate on any site

Visit any website and click the bookmark. Hover over text to see its font details in a floating panel.

03

Copy the CSS

Click any element to lock the panel, then click Copy CSS to copy all font properties at once.
